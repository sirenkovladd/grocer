# External Receipt Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pull receipt data from external loyalty APIs (PC Optimum first, others later) into Grocer, reconciling with existing photo-OCR receipts so the catalog learns UPCs and exact item identities from a trusted source.

**Architecture:** New `internal/sources/` package defines a `Source` interface (one implementation per website). A `Manager` runs all registered sources, calls `ListEvents`/`GetEventDetails` (or site equivalents), maps the response to a normalized `*NormalizedReceipt`, and hands it to a `receipt.Syncer` that does idempotent upsert + item matching. The matcher is upgraded to short-circuit on UPC/LIAM before doing fuzzy name lookup, so already-seen items are matched in O(1). The PC Optimum implementation lives in `internal/sources/pcoptimum/` and uses a per-account bearer token (manual entry for MVP).

**Tech Stack:** Go 1.25+, `net/http`, `encoding/json`, memdb schema extensions, protobuf for new fields, VanJS for the connection-settings UI, existing `internal/receipt/` matcher and proposal flow.

**UX spec:** `docs/superpowers/specs/2026-07-13-sources-ux.md` — defines the user-facing flow for connecting an account, the notification bell behavior, the duplicate banner on photo upload, and the state machines for `LoyaltyAccount.status` and notification lifecycle. **Read this before implementing Tasks 11, 11b, and 13b** — the implementation is correct, but the design decisions (modal vs. page, when to notify, when to escalate) live in the spec, not the plan.

## Open Decisions (assumptions baked into this plan)

These are the choices I had to make. Flag any you want to revisit before execution:

1. **Auth — manual token entry (MVP).** The user pastes a PC Optimum bearer token + memberId in Settings. We do not implement the Oracle IDCS OAuth dance in this plan. The token is stored in the `LoyaltyAccount` entity and used as `Authorization: Bearer <token>` on each call. Token refresh is **out of scope**; we surface a 401 error and prompt the user to re-paste.
2. **Sync trigger — manual button (MVP).** The user clicks "Sync now" on a connection. A background ticker that polls every N minutes is a follow-up (Phase 6), not in this plan.
3. **One loyalty account per user, per source.** The family-shared data model means each user can have their own PC Optimum connection (mirrors `BotUser` mapping). A `UserID → []LoyaltyAccount` is what we need; `LoyaltyAccount` itself is unique on `(userId, source, memberId)`.
4. **Shoppers Drug Mart is in scope, not separated.** PC Optimum's point-events feed mixes LCL (No Frills / Loblaws) and SDM transactions under the same `memberId`. The PC Optimum `Source` implementation handles both — we just map `storeBanner` to a `Merchant` name like "Joti's NOFRILLS Vancouver" and "SHOPPERS DRUG MART CAMBIE VILLAGE".
5. **Reconciliation with photo receipts is explicit, not magic.** When the API yields an event whose `date + totalCents + merchant` matches an existing photo receipt, we **do not auto-merge**. Instead, we (a) keep the photo receipt as-is, (b) stamp UPC/LIAM on its items by matching API items to photo items by line total, and (c) show the API's `externalId` in the UI as "verified by PC Optimum". Future phase can add auto-merge.
6. **Item identity precedence: UPC > LIAM > name fuzzy match.** UPC and LIAM are first-class identifiers. If a new API item has a UPC that exists in `items` already, we reuse that item (adding the UPC and any new aliases). Same for LIAM. Only when both are absent do we fall back to the existing fuzzy matcher.
7. **Token storage is plaintext in the snapshot.** The snapshot already contains password hashes, so adding a token is the same threat model. Encrypting at rest is a separate hardening pass.

## Global Constraints

- `fixed64` / `uint64` IDs for everything that already uses them. Don't introduce `string` IDs for the new entity.
- New proto fields are added at the **end** of each message (don't renumber existing tags). The `protoc` output stays compatible with existing snapshots.
- Token is sent in the `Authorization: Bearer` header on every source HTTP call. Never log the token. The PC Optimum `x-lcl-apikey` is a **public** constant hard-coded in `client.go`; it is not a secret and is safe to commit.
- The PC Optimum base URL is `https://api.pcoptimum.ca/loyalty/members-api/v2/member`. The two endpoints are:
  - `GET /point-events?memberId={id}&language=en-CA&offset={n}&limit={n}` — list
  - `GET /point-event?memberId={id}&pointEventId={id}&language=en-CA` — detail
- All third-party HTTP clients reuse the existing `http.Client` timeout pattern from `internal/llm/base.go` (180s default; 30s is plenty for these short JSON reads — override per client).
- `mise run build_client`, `go build ./...`, and `go test ./...` must pass at the end of each task.
- **No headless browser automation** for tests. The PC Optimum tests use `httptest.NewServer` to stub the remote API.
- The plan intentionally does **not** modify `internal/receipt/parser.go`. Photo parsing stays separate; PC Optimum goes through the new `Syncer`.
- **New env var `SOURCES_SYNC_INTERVAL`** (Go duration string, default `15m`). The background ticker reads it at boot. Setting to `0` or an unparseable value falls back to default.

```go
// CompoundIndexer joins the UserID, Source, and MemberID fields
// with a NUL separator to produce a unique string key.
type compoundAccountIndexer struct{}

func (compoundAccountIndexer) FromObject(obj interface{}) (bool, []byte, error) {
	a, ok := obj.(*domain.LoyaltyAccount)
	if !ok {
		return false, nil, nil
	}
	key := fmt.Sprintf("%d\x00%s\x00%s", a.UserID, a.Source, a.MemberID)
	return true, []byte(key), nil
}

func (compoundAccountIndexer) FromArgs(args ...interface{}) ([]byte, error) {
	if len(args) != 3 {
		return nil, fmt.Errorf("user_source_member index requires 3 args")
	}
	userID, ok1 := args[0].(uint64)
	source, ok2 := args[1].(string)
	memberID, ok3 := args[2].(string)
	if !ok1 || !ok2 || !ok3 {
		return nil, fmt.Errorf("user_source_member index: bad arg types")
	}
	return []byte(fmt.Sprintf("%d\x00%s\x00%s", userID, source, memberID)), nil
}
```

```go
// NormalizedEvent is one event as listed by a source — typically
// lighter than the full receipt (no line items). The syncer calls
// ListEvents, then GetEventDetails for each, then upserts.
type NormalizedEvent struct {
	ExternalID         string    // stable ID in the source system (e.g. PC Optimum pointEventId)
	Date               time.Time // transaction time
	TotalCents         int64
	MerchantName       string    // e.g. "Joti's NOFRILLS Vancouver"

	StoreCity          string
	StoreProvince      string

type NormalizedReceipt struct {
	Event      NormalizedEvent
	Items      []NormalizedItem
	RawJSON    string // preserved for the receipt's ExternalMetadataJSON

	LIAM           string  // source-specific product ID, "" if unknown
	Quantity       float64 // 0.92 for "0.92 kg"
	UnitPriceCents int64   // per-unit; 0 if weighted
	TotalPriceCents int64
```

```go
package sources

import (
	"context"
	"errors"

	"code.sirenko.ca/grocer/internal/domain"

// Source is implemented once per external receipt provider. Each
// implementation is responsible for authenticating with the upstream
// API and mapping its response to the cross-site Normalized* types.
type Source interface {
	// Name returns the lowercase identifier used in URLs, the
	// Receipt.Source field, and the LoyaltyAccount.Source column.
	// Examples: "pcoptimum".
	Name() string

	// ListEvents fetches all events the account has on the source.
	// The implementation is responsible for pagination; the syncer
	// calls this once per sync and consumes the full result.
	ListEvents(ctx context.Context, account *domain.LoyaltyAccount) ([]NormalizedEvent, error)

	// GetEventDetails fetches the full receipt (with line items)
	// for a single event. The syncer is expected to have just
	// enumerated the events via ListEvents, so the implementation
	// does not need to re-derive list-only fields (e.g. event
	// category). The returned NormalizedReceipt's Event is treated
	// as authoritative for date/total/merchant; the syncer
	// overwrites it with the matching list-event so list-only
	// fields (sourceCategory, etc.) make it into the final receipt.
	GetEventDetails(ctx context.Context, account *domain.LoyaltyAccount, externalID string) (*NormalizedReceipt, error)
}

// ErrAuthExpired signals that the upstream rejected the access
// token. The handler should surface this to the user and ask them
// to re-paste the token.
var ErrAuthExpired = errors.New("source: authentication expired")

// ErrRateLimited signals the upstream asked us to back off. The
// syncer surfaces this so the caller can retry later.
var ErrRateLimited = errors.New("source: rate limited")
```

```go
package pcoptimum

	"fmt"
	"io"
	"net/http"
	"net/url"
	"strings"
	"time"
)

const BaseURL = "https://api.pcoptimum.ca/loyalty/members-api/v2/member"

const APIKey = "6k4rDq3Cbbi92IcnQkWod0fh0ZYGXyTw"

type Client struct {
	httpClient *http.Client
}

func NewClient() *Client {
	return &Client{
		// 30s is plenty for these short JSON reads; the LLM
		// base uses 180s but that's because LLM streams are slow.
		httpClient: &http.Client{Timeout: 30 * time.Second},
	}
}

// doGet issues a GET against path on the PC Optimum members API,
// adding the standard browser-shaped headers the API expects, and
// decodes the JSON body into out. Returns ErrAuthExpired on 401.
func (c *Client) doGet(ctx context.Context, token, path string, query url.Values, out any) error {
	u := BaseURL + path
	if len(query) > 0 {
		u += "?" + query.Encode()
	}

	req, err := http.NewRequestWithContext(ctx, http.MethodGet, u, nil)
	if err != nil {
		return fmt.Errorf("new request: %w", err)
	}

	// These headers match what a real browser sends; the API
	// has been observed to reject requests missing x-lcl-apikey
	// or the channel-type / devicefingerprint headers.
	req.Header.Set("Authorization", "Bearer "+token)
	req.Header.Set("Accept", "application/json, text/plain, */*")
	req.Header.Set("Channel-Type", "WEB")
	req.Header.Set("X-Lcl-Apikey", APIKey)
	req.Header.Set("X-Lcl-Client-Date-Time", time.Now().UTC().Format("2006-01-02T15:04:05"))

	resp, err := c.httpClient.Do(req)
	if err != nil {
		return fmt.Errorf("http: %w", err)
	}
	defer resp.Body.Close()

	body, err := io.ReadAll(resp.Body)
	if err != nil {
		return fmt.Errorf("read body: %w", err)
	}

	switch resp.StatusCode {
	case http.StatusOK:
		if out == nil {
			return nil
		}
		if err := json.Unmarshal(body, out); err != nil {
			return fmt.Errorf("decode %s: %w", path, err)
		}
		return nil
	case http.StatusUnauthorized, http.StatusForbidden:
		// Surface a typed error so the handler can ask the user
		// to re-paste their token.
		return fmt.Errorf("%w (status %d): %s", ErrAuthExpired, resp.StatusCode, truncate(string(body), 200))
	default:
		return fmt.Errorf("pcoptimum %s: status %d: %s", path, resp.StatusCode, truncate(string(body), 200))
	}
}

func truncate(s string, n int) string {
	if len(s) <= n {
		return s
	}
	return strings.ToValidUTF8(s[:n], "") + "...(truncated)"
}
```

```go
package receipt

import (
	"context"
	"fmt"
	"log"

	"code.sirenko.ca/grocer/internal/domain"
	"code.sirenko.ca/grocer/internal/llm"
	"code.sirenko.ca/grocer/internal/sources"
	"code.sirenko.ca/grocer/internal/store"
)

// SyncOutcome summarizes what Upsert did. Returned to the API
// handler so it can report "created 3 receipts, updated 1, added
// 2 new items, learned 5 UPCs".
type SyncOutcome struct {
	Action            string // "created" | "updated" | "skipped"
	ReceiptID         uint64
	NewItemsCreated   int
	UPCsAdded         int
	LIAMsAdded        int
	NewAliasesAdded   int
}

// Syncer turns a NormalizedReceipt from any source into a stored
// Receipt, doing the item matching, alias learning, and category
// assignment in one place. Reused by sources.Manager and (eventually)
// by future sources.
type Syncer struct {
	store    *store.Store
	llm      llm.Provider
	matcher  *Matcher
}

func NewSyncer(s *store.Store, p llm.Provider, m *Matcher) *Syncer {
	return &Syncer{store: s, llm: p, matcher: m}
}

// Upsert finds an existing receipt by (source, externalID) and
// either creates or updates it. Idempotent: re-running on the same
// externalID with identical data is a no-op (`skipped`).
func (y *Syncer) Upsert(ctx context.Context, sourceName string, ownerID uint64, n *sources.NormalizedReceipt) (*SyncOutcome, error) {
	existing, err := y.store.GetReceiptByExternalID(n.Event.ExternalID)
	if err != nil && err != store.ErrNotFound {
		return nil, fmt.Errorf("lookup existing: %w", err)
	}

	// If we already have this receipt AND the totals match, skip.
	// We don't try to detect item-level changes — if the upstream
	// updates a line, the user can re-sync or edit the receipt.
	if existing != nil && existing.TotalCents == n.Event.TotalCents {
		return &SyncOutcome{Action: "skipped", ReceiptID: existing.ReceiptID}, nil
	}

	merchant, err := y.findOrCreateMerchant(n.Event.MerchantName)
	if err != nil {
		return nil, fmt.Errorf("merchant: %w", err)
	}

	receiptItems, outcome, err := y.matchAndCreateItems(ctx, merchant.MerchantID, n.Items)
	if err != nil {
		return nil, fmt.Errorf("items: %w", err)
	}
	outcome.ReceiptID = existingReceiptID(existing)

	if existing != nil {
		// Update in place — keep ReceiptID, swap everything else.
		existing.MerchantID = merchant.MerchantID
		existing.Date = n.Event.Date.Unix()
		existing.Items = receiptItems
		existing.TotalCents = n.Event.TotalCents
		existing.ExternalMetadataJSON = n.RawJSON
		if err := y.store.UpdateReceipt(existing); err != nil {
			return nil, fmt.Errorf("update: %w", err)
		}
		outcome.Action = "updated"
	} else {
		r := &domain.Receipt{
			ReceiptID:           y.store.ReceiptID.Gen(),
			MerchantID:          merchant.MerchantID,
			OwnerID:             ownerID,
			Date:                n.Event.Date.Unix(),
			Items:               receiptItems,
			TotalCents:          n.Event.TotalCents,
			Source:              sourceName,
			ExternalID:          n.Event.ExternalID,
			ExternalMetadataJSON: n.RawJSON,
		}
		if err := y.store.CreateReceipt(r); err != nil {
			return nil, fmt.Errorf("create: %w", err)
		}
		outcome.ReceiptID = r.ReceiptID
		outcome.Action = "created"
	}

	return outcome, nil
}

func existingReceiptID(r *domain.Receipt) uint64 {
	if r == nil {
		return 0
	}
	return r.ReceiptID
}

// matchAndCreateItems walks the normalized items, looking each up
// by UPC → LIAM → name, and creates new items for the misses.
// Returns the receipt-line slice and an in-progress SyncOutcome.
func (y *Syncer) matchAndCreateItems(ctx context.Context, merchantID uint64, items []sources.NormalizedItem) ([]domain.ReceiptItem, *SyncOutcome, error) {
	outcome := &SyncOutcome{}
	receiptItems := make([]domain.ReceiptItem, 0, len(items))

	for _, n := range items {
		matched, err := y.matcher.FindMatchByUPC(n.UPC)
		if err != nil && err != store.ErrNotFound {
			return nil, nil, err
		}
		if matched == nil {
			matched, err = y.matcher.FindMatchByLIAM(n.LIAM)
			if err != nil && err != store.ErrNotFound {
				return nil, nil, err
			}
		}
		if matched == nil {
			matched, _, err = y.matcher.FindMatch(n.RawName, "", "")
			if err != nil {
				return nil, nil, err
			}
		}

		if matched != nil {
			// Augment the existing item with any UPC/LIAM/alias we
			// learned from this API ingest. This is how the catalog
			// grows over time.
			enriched, err := y.enrichItem(matched, n)
			if err != nil {
				return nil, nil, err
			}
			if enriched.UPCAdded {
				outcome.UPCsAdded++
			}
			if enriched.LIAMAdded {
				outcome.LIAMsAdded++
			}
			if enriched.AliasesAdded > 0 {
				outcome.NewAliasesAdded += enriched.AliasesAdded
			}
			receiptItems = append(receiptItems, domain.ReceiptItem{
				ItemID:         matched.ItemID,
				Quantity:       n.Quantity,
				UnitPriceCents: n.UnitPriceCents,
			})
			continue
		}

		// No match. Create a new item; run LLM categorization.
		item := &domain.Item{
			ItemID:     y.store.ItemID.Gen(),
			Name:       n.RawName,
			Normalized: normalizeName(n.RawName),
			Aliases:    []string{n.RawName},
			UPC:        n.UPC,
			LIAM:       n.LIAM,
			MerchantID: merchantID,
		}
		cat, err := y.categorizeItem(ctx, n.RawName)
		if err == nil {
			item.CategoryID = cat.CategoryID
		} else {
			log.Printf("syncer: categorize %q failed: %v", n.RawName, err)
		}
		if err := y.store.CreateItem(item); err != nil {
			return nil, nil, fmt.Errorf("create item %q: %w", n.RawName, err)
		}
		outcome.NewItemsCreated++
		receiptItems = append(receiptItems, domain.ReceiptItem{
			ItemID:         item.ItemID,
			Quantity:       n.Quantity,
			UnitPriceCents: n.UnitPriceCents,
		})
	}

	return receiptItems, outcome, nil
}

type enrichResult struct {
	UPCAdded     bool
	LIAMAdded    bool
	AliasesAdded int
}

// enrichItem adds any new identifiers and aliases to an existing
// item. Persists if anything changed. Returns a tiny result so the
// syncer can report aggregate counts.
func (y *Syncer) enrichItem(it *domain.Item, n sources.NormalizedItem) (enrichResult, error) {
	var res enrichResult
	changed := false

	if n.UPC != "" && it.UPC == "" {
		it.UPC = n.UPC
		res.UPCAdded = true
		changed = true
	}
	if n.LIAM != "" && it.LIAM == "" {
		it.LIAM = n.LIAM
		res.LIAMAdded = true
		changed = true
	}
	// Add the upstream's raw name as an alias (e.g. "S&W PIMPL SLICE
	// MRJ" → an alias of "S&W Pineapple Slices"). Dedupe.
	for _, a := range it.Aliases {
		if normalizeName(a) == normalizeName(n.RawName) {
			a = ""
			break
		}
	}
	if !hasAlias(it.Aliases, n.RawName) && normalizeName(n.RawName) != normalizeName(it.Name) {
		it.Aliases = append(it.Aliases, n.RawName)
		res.AliasesAdded = 1
		changed = true
	}

	if changed {
		if err := y.store.UpdateItem(it); err != nil {
			return res, err
		}
	}
	return res, nil
}

func hasAlias(aliases []string, s string) bool {
	for _, a := range aliases {
		if a == s {
			return true
		}
	}
	return false
}

func (y *Syncer) findOrCreateMerchant(name string) (*domain.Merchant, error) {
	m, err := y.store.GetMerchantByName(name)
	if err == nil {
		return m, nil
	}
	m = &domain.Merchant{
		MerchantID: y.store.MerchantID.Gen(),
		Name:       name,
	}
	if err := y.store.CreateMerchant(m); err != nil {
		return nil, err
	}

}
```

```go
	"context"
```

```go
// SyncResult is the per-account summary returned by Manager.Sync
// and Manager.SyncAll.
type SyncResult struct {
	AccountID      uint64
	Source         string
	EventsScanned  int
	Created        int
	Updated        int
	Skipped        int
	NewItemsAdded  int
	UPCsAdded      int
	LIAMsAdded     int
	AliasesAdded   int
	AuthError      bool  // true if the source returned ErrAuthExpired
	OtherError     string // non-auth error, empty if none
}

type Manager struct {
	store   *store.Store
	syncer  *receipt.Syncer
	sources map[string]Source
}

func NewManager(s *store.Store, syncer *receipt.Syncer) *Manager {
	return &Manager{
		store:   s,
		syncer:  syncer,
		sources: make(map[string]Source),
	}
}

func (m *Manager) Register(s Source) {
	m.sources[s.Name()] = s
}

func (m *Manager) Names() []string {
	out := make([]string, 0, len(m.sources))
	for n := range m.sources {
		out = append(out, n)
	}
	return out
}

func (m *Manager) Sync(ctx context.Context, account *domain.LoyaltyAccount) (*SyncResult, error) {
	src, ok := m.sources[account.Source]
	if !ok {
		return nil, fmt.Errorf("manager: unknown source %q", account.Source)
	}

	// Refuse to sync accounts in the auth_expired state. The
	// background ticker skips these too, but a manual /api/sources/{id}/sync
	// call should be a no-op (and surface the auth_expired state
	// in the response) so the user can see why nothing happened.
	if account.Status == "auth_expired" {
		return &SyncResult{
			AccountID: account.LoyaltyAccountID,
			Source:    account.Source,
			AuthError: true,
		}, nil
	}

	result := &SyncResult{AccountID: account.LoyaltyAccountID, Source: account.Source}

	events, err := src.ListEvents(ctx, account)
	if err != nil {
		if errors.Is(err, ErrAuthExpired) {
			m.markAuthExpired(account, result)
			return result, nil
		}
		m.markSyncError(account, result, err)
		return result, nil
	}
	result.EventsScanned = len(events)

	for _, ev := range events {
		// Filter out non-purchase events. Refunds and adjustment
		// events would create receipts with negative totals and
		// pollute the analysis. The user opted to ignore them
		// (planning session, 2026-07-13).
		if ev.Type != "" && ev.Type != "PURCHASE" {
			result.Skipped++
			continue
		}

		// Find existing receipt by externalID; if found AND totals
		// match, the syncer will skip — but we already have the
		// event metadata, so this is a cheap check to avoid the
		// detail HTTP call on skips. If the totals differ, we
		// need to refetch and update.
		existing, _ := m.store.GetReceiptByExternalID(ev.ExternalID)
		if existing != nil && existing.TotalCents == ev.TotalCents {
			result.Skipped++
			continue
		}

		detail, err := src.GetEventDetails(ctx, account, ev.ExternalID)
		if err != nil {
			if errors.Is(err, ErrAuthExpired) {
				m.markAuthExpired(account, result)
				return result, nil
			}
			// Don't abort the whole sync on one event failing;
			// log and continue.
			log.Printf("sources: GetEventDetails(%s): %v", ev.ExternalID, err)
			continue
		}

		outcome, err := m.syncer.Upsert(ctx, account.Source, account.UserID, detail)
		if err != nil {
			log.Printf("sources: syncer.Upsert(%s): %v", ev.ExternalID, err)
			continue
		}
		switch outcome.Action {
		case "created":
			result.Created++
		case "updated":
			result.Updated++
		case "skipped":
			result.Skipped++
		}
		result.NewItemsAdded += outcome.NewItemsCreated
		result.UPCsAdded += outcome.UPCsAdded
		result.LIAMsAdded += outcome.LIAMsAdded
		result.AliasesAdded += outcome.NewAliasesAdded
	}

	// Stamp lastSyncedAt on the account and clear any prior
	// transient sync error. A successful sync is the strongest
	// signal we have that the token still works.
	now := time.Now().Unix()
	account.LastSyncedAt = now
	account.LastSyncErrorAt = 0
	account.LastSyncError = ""
	if account.Status != "paused" {
		account.Status = "active"
	}
	if err := m.store.UpdateLoyaltyAccount(account); err != nil {
		log.Printf("sources: update lastSyncedAt: %v", err)
	}

	return result, nil
}

// markAuthExpired transitions the account to the auth_expired
// state, creates a user-visible notification, and stamps the
// result. The background ticker (Task 10b) will see the status
// and stop retrying until the user re-pastes the token.
func (m *Manager) markAuthExpired(account *domain.LoyaltyAccount, result *SyncResult) {
	result.AuthError = true
	now := time.Now().Unix()
	account.Status = "auth_expired"
	account.LastSyncErrorAt = now
	account.LastSyncError = "authentication expired; re-paste the token to resume"
	if err := m.store.UpdateLoyaltyAccount(account); err != nil {
		log.Printf("sources: mark auth_expired: %v", err)
	}
	// Surface a notification so the user sees it in the bell icon.
	// The title is source-aware so a user with two accounts (rare
	// but possible) sees which one is broken.
	_ = m.store.CreateNotification(&domain.Notification{
		NotificationID: m.store.NotificationID.Gen(),
		UserID:         account.UserID,
		Type:           "token_expired",
		Title:          fmt.Sprintf("%s token expired", sourceDisplayName(account.Source)),
		Message:        "Re-paste the bearer token in Settings to resume syncing.",
		Link:           "/settings",
		CreatedAt:      now,
	})
}

// markSyncError records a non-auth sync failure on the account
// but keeps status=active so the next tick retries. Surfaces a
// notification only if the error persists (kept simple for MVP:
// always notify).
func (m *Manager) markSyncError(account *domain.LoyaltyAccount, result *SyncResult, err error) {
	result.OtherError = err.Error()
	now := time.Now().Unix()
	account.LastSyncErrorAt = now
	account.LastSyncError = err.Error()
	if err := m.store.UpdateLoyaltyAccount(account); err != nil {
		log.Printf("sources: mark sync error: %v", err)
	}
	_ = m.store.CreateNotification(&domain.Notification{
		NotificationID: m.store.NotificationID.Gen(),
		UserID:         account.UserID,
		Type:           "sync_error",
		Title:          fmt.Sprintf("%s sync failed", sourceDisplayName(account.Source)),
		Message:        err.Error(),
		Link:           "/settings",
		CreatedAt:      now,
	})
}

func sourceDisplayName(s string) string {
	switch s {
	case "pcoptimum":
		return "PC Optimum"
	default:
		return s
	}
}

func (m *Manager) SyncAll(ctx context.Context) ([]*SyncResult, error) {
	accounts, err := m.store.ListLoyaltyAccounts()
	if err != nil {
		return nil, err
	}
	var out []*SyncResult
	for _, a := range accounts {
		r, _ := m.Sync(ctx, a)
		out = append(out, r)
	}
	return out, nil
}
```

```go
		// The manager doesn't expose Lookup; add it as part of this task.
		writeError(w, http.StatusBadRequest, "unknown source: "+body.Source)
		return

		LoyaltyAccountID: r.store.LoyaltyAccountID.Gen(),
		UserID:           uid,

		MemberID:         body.MemberID,
		DisplayName:      body.DisplayName,

	}

		writeError(w, http.StatusInternalServerError, "create failed")
		return

}

func (r *Router) handleDisconnectSource(w http.ResponseWriter, req *http.Request) {
	uid := r.getUserID(req)
	idStr := req.PathValue("id")
	id, err := strconv.ParseUint(idStr, 10, 64)
	if err != nil {
		writeError(w, http.StatusBadRequest, "invalid ID")
		return

	a, err := r.store.GetLoyaltyAccount(id)
	if err != nil {
		writeError(w, http.StatusNotFound, "not found")
		return
	}
	if a.UserID != uid {
		writeError(w, http.StatusForbidden, "not your account")
		return
	}
	if err := r.store.DeleteLoyaltyAccount(id); err != nil {
		writeError(w, http.StatusInternalServerError, "delete failed")
		return

}

func (r *Router) handleSyncSource(w http.ResponseWriter, req *http.Request) {
	uid := r.getUserID(req)
	idStr := req.PathValue("id")
	id, err := strconv.ParseUint(idStr, 10, 64)
	if err != nil {
		writeError(w, http.StatusBadRequest, "invalid ID")
		return
	}
	a, err := r.store.GetLoyaltyAccount(id)
	if err != nil {
		writeError(w, http.StatusNotFound, "not found")
		return
	}
	if a.UserID != uid {
		writeError(w, http.StatusForbidden, "not your account")
		return
	}

	// Per-account cooldown. PC Optimum does not publish rate limits
	// but a stuck-frontend retry loop or a curious family member
	// hammering the button can burn the user's IP and get the
	// account flagged. 30s is tight enough to discourage abuse
	// and loose enough that a real user can re-sync after a typo.
	const cooldown = 30 * time.Second
	if a.LastSyncedAt != 0 && time.Since(time.Unix(a.LastSyncedAt, 0)) < cooldown {
		writeError(w, http.StatusTooManyRequests,
			fmt.Sprintf("synced recently; try again in %s", time.Until(time.Unix(a.LastSyncedAt, 0).Add(cooldown)).Round(time.Second)))
		return
	}

	// Use a fresh context with a sensible timeout (matches the
	// HTTP client; the source can paginate many events).
	ctx, cancel := context.WithTimeout(req.Context(), 5*time.Minute)
	defer cancel()

	result, err := r.sourcesManager.Sync(ctx, a)
	if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	writeJSON(w, http.StatusOK, result)
}
```

**Files:**

- Produces: `Ticker` goroutine that periodically calls `Manager.Sync` on every active `LoyaltyAccount`. On auth-expired, the ticker stops calling that account and writes a notification. On token re-paste, the account's status flips back to `active` and the ticker resumes it.

- [ ] **Step 1: Implement the ticker**

Create `internal/sources/ticker.go`:

```go
package sources

import (
	"context"
	"log"
	"time"

	"code.sirenko.ca/grocer/internal/domain"
	"code.sirenko.ca/grocer/internal/store"
)

// Ticker periodically syncs all active loyalty accounts.
type Ticker struct {
	store    *store.Store
	manager  *Manager
	interval time.Duration
}

func NewTicker(s *store.Store, m *Manager, interval time.Duration) *Ticker {
	return &Ticker{store: s, manager: m, interval: interval}
}

// Run blocks until ctx is cancelled. Spawns one sync per account
// per tick; the per-account cooldown inside Manager.Sync prevents
// tight retry loops if a sync is fast. If an account is in
// auth_expired state, it's skipped (the user must re-paste the
// token to resume).
func (t *Ticker) Run(ctx context.Context) {
	log.Printf("sources: ticker started, interval=%s", t.interval)
	tick := time.NewTicker(t.interval)
	defer tick.Stop()

	// One immediate tick so a fresh server doesn't wait 15min
	// before its first sync.
	t.tick(ctx)

	for {
		select {
		case <-ctx.Done():
			log.Printf("sources: ticker stopped")
			return
		case <-tick.C:
			t.tick(ctx)
		}
	}
}

func (t *Ticker) tick(ctx context.Context) {
	accounts, err := t.store.ListLoyaltyAccounts()
	if err != nil {
		log.Printf("sources: ticker list accounts: %v", err)
		return
	}
	for _, a := range accounts {
		// Skip paused and auth_expired accounts. The Manager
		// will re-check auth_expired and refuse anyway, but
		// filtering here avoids the HTTP round-trip and the
		// extra log noise.
		if a.Status == "paused" || a.Status == "auth_expired" {
			continue
		}
		// Per-account cooldown: if a manual sync just ran, don't
		// race it. The cooldown inside Manager.Sync covers the
		// racing sync case too, but skipping here saves the
		// HTTP call.
		if a.LastSyncedAt != 0 && time.Since(time.Unix(a.LastSyncedAt, 0)) < 30*time.Second {
			continue
		}
		if _, err := t.manager.Sync(ctx, a); err != nil {
			log.Printf("sources: ticker sync account %d: %v", a.LoyaltyAccountID, err)
		}
	}
}
```

**Interfaces:**

This is a softer reconciliation than the plan's "decisions" suggest: it does not merge or delete; it just enriches the photo receipt's items with identifiers the API knows.

- [ ] **Step 1: Implement `ReconcileWithPhotoReceipt`**

Add to `internal/receipt/syncer.go`:

```go
// ReconcileWithPhotoReceipt tries to backfill UPC/LIAM from a
// freshly-synced API receipt onto an existing photo receipt that
// matches it (same merchant, same date, same total). For each
// API item, find a photo item with the same total cost; if the
// photo item's underlying Item has no UPC/LIAM yet, stamp them
// from the API item and persist.
//
// Returns the number of items enriched. The photo receipt is
// always updated as a single store write even if nothing changed
// (to keep the snapshot logic simple).
func (y *Syncer) ReconcileWithPhotoReceipt(apiReceipt *domain.Receipt, photoReceipt *domain.Receipt) (int, error) {
	enriched := 0
	// Build a map from totalCostCents → photo receipt line index.
	type photoLine struct {
		idx      int
		quantity float64
		total    int64
		itemID   uint64
	}
	photoLines := make([]photoLine, len(photoReceipt.Items))
	for i, ri := range photoReceipt.Items {
		photoLines[i] = photoLine{idx: i, quantity: ri.Quantity, total: int64(math.Round(ri.Quantity * float64(ri.UnitPriceCents))), itemID: ri.ItemID}
	}

	for _, apiRI := range apiReceipt.Items {
		// Load the API item to get UPC/LIAM.
		apiItem, err := y.store.GetItem(apiRI.ItemID)
		if err != nil {
			continue
		}
		if apiItem.UPC == "" && apiItem.LIAM == "" {
			continue
		}
		// Find a matching photo line: same totalCents (rounded).
		for i, pl := range photoLines {
			if pl.total != int64(math.Round(apiRI.Quantity*float64(apiRI.UnitPriceCents))) {
				continue
			}
			photoItem, err := y.store.GetItem(pl.itemID)
			if err != nil {
				break
			}
			changed := false
			if apiItem.UPC != "" && photoItem.UPC == "" {
				photoItem.UPC = apiItem.UPC
				changed = true
			}
			if apiItem.LIAM != "" && photoItem.LIAM == "" {
				photoItem.LIAM = apiItem.LIAM
				changed = true
			}
			if changed {
				if err := y.store.UpdateItem(photoItem); err != nil {
					return enriched, err
				}
				enriched++
			}
			// Consume the photo line so a second API item with the
			// same total doesn't double-match.
			photoLines = append(photoLines[:i], photoLines[i+1:]...)
			break
		}
	}

	if enriched > 0 {
		// Touch the photo receipt so the snapshot picks up the
		// updated item references on the next reload.
		if err := y.store.UpdateReceipt(photoReceipt); err != nil {
			return enriched, err
		}
	}
	return enriched, nil
}
```

```go
func (s *Store) ListReceiptsByMerchantAndDate(merchantID uint64, dateUnix int64) ([]*domain.Receipt, error) {
	s.mu.RLock()
	defer s.mu.RUnlock()

	txn := s.db.Txn(false)
	defer txn.Abort()

	iter, err := txn.Get("receipts", "merchant_id", merchantID)
	if err != nil {

	}
	const day = int64(24 * 60 * 60)
	var out []*domain.Receipt
	for raw := iter.Next(); raw != nil; raw = iter.Next() {
		r := raw.(*domain.Receipt)
		if r.Date >= dateUnix-day && r.Date <= dateUnix+day {
			out = append(out, r)
		}
	}
	return out, nil
}
```

```go
// FindSimilarReceipts returns receipts that look like the same
// transaction as the given candidate (same merchant, same total,
// date within ±24h). Used by the photo upload handler to warn
// the user when a photo receipt might be a duplicate of one
// already in the store (from any source, including PC Optimum).
//
// excludeID is the ID of a receipt to skip (e.g. a candidate's
// own ID, or the photo receipt being updated). Pass 0 to include
// all.
func (s *Store) FindSimilarReceipts(merchantID uint64, totalCents int64, dateUnix, excludeID uint64) ([]*domain.Receipt, error) {
	s.mu.RLock()
	defer s.mu.RUnlock()

	txn := s.db.Txn(false)
	defer txn.Abort()

	iter, err := txn.Get("receipts", "merchant_id", merchantID)
	if err != nil {
		return nil, err
	}
	const day = int64(24 * 60 * 60)
	var out []*domain.Receipt
	for raw := iter.Next(); raw != nil; raw = iter.Next() {
		r := raw.(*domain.Receipt)
		if r.ReceiptID == excludeID {
			continue
		}
		if r.TotalCents != totalCents {
			continue
		}
		if r.Date < dateUnix-day || r.Date > dateUnix+day {
			continue
		}
		out = append(out, r)
	}
	return out, nil
}
```

## Out of Scope (Follow-up Tickets)

These are explicitly **not** in this plan. Capture them as follow-up tickets at the end:

1. **Token refresh** — when the bearer token expires, prompt the user to re-paste. Add a background job that calls the IDCS refresh endpoint when `tokenExpiresAt - now < 5min`.
2. **Additional sources** — Air Miles, Scene+, Aeroplan, RBC Avion, etc. Each gets its own package under `internal/sources/<name>/` and is `Register`ed in `cmd/server/main.go`.
3. **Auto-merge of duplicate receipts** — currently we treat API and photo as separate receipts even if they match. A future pass could merge them (keeping the photo for the receipt's visual record, but using the API for the structured data). The duplicate-detection banner (Task 13b) is the first step toward this.
4. **Encrypted token storage** — move the access token out of the plaintext snapshot into an encrypted field (envelope-encrypted with a key from env or KMS). This is meaningfully harder than password hashing because tokens need to be decrypted for every API call. Today's snapshot threat model is "anyone who can read GCS can read tokens" — acceptable for a family tool, but worth flagging.
5. **OCR UPC extraction** — the user's example `888811158088 S&W PIMPL SLICE MRJ 3.29` shows that UPCs often appear in OCR text. The plan only matches by UPC when the API provides one; OCR-only receipts with UPCs in the printed text still go through fuzzy name matching and create duplicates of "S&W Pineapple Slices". A follow-up should update the LLM extraction prompt to extract UPCs from line items and populate `Item.UPC` at proposal time, so the matcher hits the same UPC fast-path. This is arguably a bigger data-quality win than API ingest for the majority of receipts that come from photos, not APIs.
